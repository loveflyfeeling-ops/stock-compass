# 量價羅盤 Stock Compass

台股智能選股網頁：依趨勢、動能、量能、相對強弱與法人籌碼評分，給出進場區間、停損、停利與移動停利，並提供爆發雷達、法人籌碼排行（外資／投信、吸籌與出貨偵測）、產業資金流向、本益比與殖利率、自選盯盤、持股健診與名詞小學堂。

## 資料更新
| 工作流程 | 時間（台北） | 內容 |
|---|---|---|
| 盤中報價更新 | 週一至週五 09:00–13:55，約每 5 分鐘 | `scripts/live.py`：證交所即時報價（取不到改用 Yahoo Finance）→ `data/live.json` |
| 盤後資料更新 | 週一至週五 17:10 | `scripts/eod.py`：證交所與櫃買中心收盤行情（含新上市櫃股票自動加入）、外資與投信買賣超（證交所＋櫃買中心，缺漏日自動補抓）、本益比／淨值比／殖利率 → `data/raw.json` |

網頁每分鐘自動讀取最新報價並重算評分。GitHub 排程在尖峰時段可能延遲數分鐘。

## 檔案
- `index.html`：網頁本體
- `data/raw.json`：歷史日 K、成交量（保留最近 160 個交易日）、外資與投信買賣超（最近 20 日）與估值
- `data/live.json`：最新盤中報價

## 聲明
本工具為研究與教學用途，依公開資料以固定規則計算，不構成投資建議，也不保證獲利。
